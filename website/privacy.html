Your work stays yours

Privacy, plainly.

Screen Reel needs no account and sends no telemetry. Recordings, edits, voice cleanup, and exports stay on your Mac. The app requests on-device speech recognition for captions.

Recording permissions

macOS controls screen, microphone, camera, and input monitoring access. Screen Reel uses the sources you enable. Keyboard capture is off by default; enabling it records key codes and modifiers for shortcut overlays.

Update checks

The app can contact GitHub to check for a newer release. Automatic checks happen at most once every 24 hours and can be disabled in the app menu. A manual “Check for Updates” also contacts GitHub. GitHub receives your IP address and an app version in the User-Agent. Your recordings and project data are not included.

License keys

License keys are verified locally. They do not require an online activation service. Features are currently available without a license key.

This website

This site uses no analytics scripts, cookies, remote fonts, or media uploads. GitHub Pages serves the page and receives ordinary web requests. The style illustration runs in your browser. Copy buttons write only the displayed commands to your clipboard after you click.

Inspect the implementation

The source code and project format are available to inspect. Please report questions or discrepancies through the repository’s issues.
